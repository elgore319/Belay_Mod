## Belay 0.6.11

**The dev menu is now hidden and has a tileset picker.**

- The dev tools left the F7 menu. They're in their own window that only opens with **Ctrl + Shift + F9**, so normal players won't come across them. Press it again (or X) to close.
- New **Tilesets** page: untick any of the game's tilesets (the different versions of each area) to leave them out of the run. It applies to levels that haven't been generated yet, so set it before starting a run.
- In a lobby, the host's choice applies to everyone, so all players still get the same levels. Teammates see the host's choice but can't change it.
- If you untick every tileset of an area, that area ignores the picker instead of breaking generation.
- The Teleport page (teleports, Invincible, Fly) is unchanged.

Everyone in a lobby should update to 0.6.11 so the host's tileset choice is applied on every PC.
