## Tethered 0.7.49

- **A full multiplayer page on the main menu.** The TETHERED entry in the main menu (and the menu key, F7 by default) now opens a full-screen page styled like the game's menus instead of the small window. Pick Lobby, Players, Rules, Outfit, Mods or Settings on the left. Back or Esc returns to the game's menu.
- **Go to the campaign from there.** The CAMPAIGN button takes you straight to the game's campaign screen to start the run. In a lobby the host's start brings everyone along, as before.
- **Outfit preview.** On the page, the Outfit section shows your climber next to the outfit choices.
- In a run, the pause menu entry and the menu key still open the small window.

Everyone in the lobby should update.
