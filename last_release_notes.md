## Belay 0.5.27

**Picking the shortcut now blocks the normal path straight away.**

- In 0.5.26, when the team voted for a shortcut, the normal path stayed open until someone actually opened the shortcut, so you could still walk the normal route.
- Now the barrier goes up across the normal path as soon as the vote picks the shortcut.
- Anyone who gets past it into the next part of the normal route is put back below it with a reminder to take the shortcut. This stops once the shortcut has opened.
