## Belay 0.5.28

**Pitons and dropped items are shared.**

- When you hammer a piton into a wall, it appears for every teammate in the same spot, and anyone can climb on it.
- Hammering a piton in is shared too, so a piton you secured is secure for everyone. If a loose piton works free and breaks under someone, it breaks for the whole team.
- Items you drop or throw already showed up for teammates. Now, once the item stops rolling, everyone's copy snaps to the exact spot where it landed for you, so trading is easy: drop it, and your teammate picks it up with the normal pickup. Whoever grabs it first gets it, and it disappears for everyone else.
- Money is still never shared.

This version changes the network protocol, so everyone in the lobby needs 0.5.28.
