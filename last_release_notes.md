## Belay 0.5.22

**Shortcut votes get their own terminal.**

- Where a level has a terminal and there are shortcuts between it and the next terminal, Belay places a second copy of that terminal beside it. The copy is for voting only: its desktop is empty and a "SHORTCUT VOTE" sign floats above it.
- Sit at it the normal way. For each shortcut ahead, the screen asks "Shortcut" or "Normal path".
- The first vote starts the team vote, and everyone sees the banner. Teammates vote by sitting at their own copy of the vote terminal. The vote keys still work too.
- A vote started at the vote terminal runs for 40 seconds, so people have time to walk over.
- The original terminal goes back to normal: sitting at it no longer starts a vote.
- If a vote terminal doesn't fit beside the original, that original terminal starts the vote like in 0.5.21.
- Results, barriers and how shortcuts open are unchanged.

Everyone in the lobby needs 0.5.22 (network protocol changed).
