## Not Alone 0.8.38

Works with the White Knuckle Core update. Everyone in a lobby needs 0.8.38 (the network protocol changed).

- **Fixed for the Core update.** The game now rolls levels, spawns and props from its own seeded randomness. Level builds, spawners, tileset picks and spawn checks use the lobby's shared seed again, so every player gets the same map.
- **Mirrored levels match.** Whether a level is mirrored is now rolled from that level's shared seed, so a level can't be flipped on one PC and not another.
- **New enemies are shared.** Hits and kills on the androids, the new drones, the heavy and rocket turrets, the gantry turret and the pseudopod count on every PC, like other enemies. The host runs their movement.
- **New tilesets.** The Core and the other new levels and transitions come through the same shared level picks as every other area.
- **New weapons are one per player.** The crossbow, flashgun, machine gun, piton grenade, bone rebar and the scissors artifact can be picked up by each player without taking them from teammates.
- **Item printer.** What the Core's item printer makes is yours alone, like a vending machine purchase.
