## Not Alone 0.7.51

- **New name: Not Alone.** The mod is now called Not Alone (White Knuckle: Not Alone), formerly Tethered. The main menu and pause menu entry, the multiplayer page, the mod menu, update messages, the installer and the docs all use the new name.
- The installer zips are now `NotAlone-0.7.51-installer.zip` and `NotAlone-0.7.51-mod-only.zip`, with "Install Not Alone.bat" and "Uninstall Not Alone.bat" inside.
- Nothing changes for existing installs: the files keep their old internal name (`BepInEx\plugins\Belay\Belay.dll`), so settings, saves and auto-updates carry on as before.
