## Tethered 0.7.43

- **Totems are their own item.** The totem is no longer a reskinned disk. Half of the save disks a level puts down are totems instead (the same ones for everyone), and vending machines and the shopkeeper sell them for 4 roaches. Using a totem you're holding still revives a dead teammate where you stand, for free.
- **Disks are back to normal.** Disks look and work like in the base game again, and you can insert them at save terminals and reformat them into a disk save.
- **Disk saves belong to the whole team.** A disk save is only used when everyone is dead, when the team would have had its game over. Then the whole team comes back from it together, so nobody respawns alone behind the mass. It can't be loaded by hand in co-op.
- **Roach revives at any terminal.** While a teammate is down, sitting at any terminal (save terminals included) offers to revive them for roaches, since the save page's disk functions are the game's own again.
- **Fixed: the game over sometimes never came.** After the first game over in a session, the next run never noticed when the whole team was dead. Every run now starts fresh.

Network change: everyone needs 0.7.43.
