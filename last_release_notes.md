## Belay 0.7.12

- **Belay is now in the game's own menus.** The main menu and the pause menu have a BELAY entry in their list of options, styled like the game's other buttons, that opens the Belay window. The old small button in the corner is gone (it only comes back if the entry can't be added, for example after a game update changes the menus). The menu key (F7 by default) still works everywhere.

Everyone in the lobby should update.
