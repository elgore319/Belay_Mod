## Belay 0.6.10

- **Walk-in shortcuts work again.** Some shortcuts (like the one in the Abyss) start when you walk or drop into them. Belay used to hold those back for a team vote, so the shortcut wasn't there and you fell. Now walking into a shortcut opens it straight away for everyone, the same shortcut on every PC. Votes at the vote terminal still work as before, and a shortcut the team voted against stays blocked.
