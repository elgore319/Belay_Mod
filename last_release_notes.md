Shortcut votes work as a choice between two paths. Your game updates to this automatically on the next launch, then asks you to restart.

## Changed
- **Shortcut vote = pick a path.** Not every shortcut has a terminal: some start when you climb into them. Every shortcut, however it starts, now pauses and asks the team "<name> found a shortcut. Which way does the team go?" Press **F1** for the shortcut or **F2** for the normal path (same keys as before, changeable in Settings). The vote ends when everyone has voted or after 20 seconds; the shortcut wins with more votes than the normal path, and anyone who doesn't vote doesn't count.
  - **Shortcut:** it opens for everyone with the same map, and a red barrier closes the normal path.
  - **Normal path:** a red barrier closes the shortcut, and whoever found it is put back where they started the vote, on the normal side.

Everyone in a lobby needs the same Belay version.
