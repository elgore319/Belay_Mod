TETHERED {VERSION} - co-op mod for White Knuckle

INSTALL
1. Close White Knuckle.
2. Extract this whole zip anywhere (right-click > Extract All).
3. Double-click "Install Tethered.bat".
   It finds your game through Steam and installs BepInEx (the mod loader) and Tethered.
   If Windows shows "Windows protected your PC", click "More info" > "Run anyway".
4. Start the game and pick TETHERED in the main menu (or press F7).

PLAY
- One player hosts a lobby and invites friends through Steam. Everyone needs Tethered {VERSION}.
- The host starts the run and everyone else follows automatically.
- Keys: F7 menu, Tab switch spectate target.

UPDATES
Tethered updates itself: new releases download when the game starts and apply after a restart.
You can switch this off in the Tethered menu > Settings.
Tethered used to be called Belay. Its files keep the old name (BepInEx\plugins\Belay\Belay.dll)
so existing installs, settings and updates keep working.

UNINSTALL
Double-click "Uninstall Tethered.bat". It removes Tethered only and leaves BepInEx and other mods alone.
