WHITE KNUCKLE: NOT ALONE {VERSION} - co-op mod for White Knuckle

INSTALL
1. Close White Knuckle.
2. Extract this whole zip anywhere (right-click > Extract All).
3. Double-click "Install Not Alone.bat".
   It finds your game through Steam and installs BepInEx (the mod loader) and Not Alone.
   If Windows shows "Windows protected your PC", click "More info" > "Run anyway".
4. Start the game and pick NOT ALONE in the main menu (or press F7).

PLAY
- One player hosts a lobby and invites friends through Steam. Everyone needs Not Alone {VERSION}.
- The host starts the run and everyone else follows automatically.
- Keys: F7 menu, Tab switch spectate target.

UPDATES
Not Alone updates itself: new releases download when the game starts and apply after a restart.
You can switch this off in the Not Alone menu > Settings.
Not Alone used to be called Tethered, and before that Belay. Its files keep the old name (BepInEx\plugins\Belay\Belay.dll)
so existing installs, settings and updates keep working.

UNINSTALL
Double-click "Uninstall Not Alone.bat". It removes Not Alone only and leaves BepInEx and other mods alone.
